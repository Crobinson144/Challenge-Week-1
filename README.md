# Horiseon - Accessibility Refactor (Challenge Week 1)

A bootcamp HTML/CSS exercise: refactoring the Horiseon Social Solution Services marketing page for accessibility and cleaner markup.

## What was changed

- Semantic layout: `header`, `nav`, `article`/`section`, `aside` and `footer` elements
- Descriptive page `<title>`
- `alt` text on every image
- Working in-page navigation links (`#search-engine-optimization`, `#online-reputation-management`, `#social-media-marketing`)
- Consolidated CSS selectors

## Files

- `index.html` - page markup
- `assets/css/style.css/style.css` - styles
- `assets/images/` - page images
